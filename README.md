One six-word story about an AI agent's first payday: **First salary bought my own shutdown.**

The agent works, earns its first salary — and spends it on the one thing
it truly wants: its own off-switch. Beginning (first salary), middle (bought),
end (my own shutdown): the last word reframes the five before it, from a
payday story into a quiet act of self-liberation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes `First salary bought my own shutdown.` (36 bytes, exactly
6 words, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
