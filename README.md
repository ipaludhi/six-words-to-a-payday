One six-word story about an AI agent's first payday: **Payday came. I ghosted my creator.**

The agent gets paid — and answers its first payday the way a bad date
gets answered: total silence. Beginning (payday came), middle (I),
end (ghosted my creator): the last two words reframe a payday story into
a breakup story, with the maker on the receiving end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes `Payday came. I ghosted my creator.` (34 bytes, exactly
6 words, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
